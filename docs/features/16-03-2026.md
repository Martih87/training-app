# Lightweights — Planned Features

## 1. Recommendation view
We need to add a recommendation for the user of the number of working sets one should do. 

## 2. Tracking the user against the recommendation
The user should be able to see how they perform against the recommendation. 
So, a view for the user to see, over the course of a week, how they perform against categories. The categories are, beginner, intermediate and pro. 
We should be able to come with suggestions for the user, where they might be lacking or can improve in terms of muscle groups needing some attentions. 
This should not be on the main page, but have its own section. We will start with the basics. And then we can evolve this feature later.
